# Online Book Store

## Project Description
The Online Book Store is a simple website developed using HTML. It allows users to browse different sections of an online bookstore through multiple web pages. The project demonstrates the use of basic HTML concepts such as hyperlinks, headings, lists, and page navigation.

## Features
- Home Page
- Books Page
- Categories Page
- Offers Page
- About Us Page
- Contact Us Page
- Simple Navigation Menu
- User-friendly Interface

## Technologies Used
- HTML5

## Project Structure

Online-Book-Store/

## Pages Description

### Home Page
The Home page welcomes users to the Online Book Store and provides navigation to all other pages.

### Books Page
The Books page displays a collection of books available in the store.

### Categories Page
The Categories page shows different book categories such as Fiction, Non-Fiction, Mystery, Romance, Science Fiction, Biography, and Educational Books.

### Offers Page
The Offers page displays special discounts and exciting offers available for customers.

### About Us Page
The About Us page provides information about the Online Book Store and its purpose.

### Contact Us Page
The Contact Us page contains contact details for customer support and communication.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Navigate through the website using the menu links.
